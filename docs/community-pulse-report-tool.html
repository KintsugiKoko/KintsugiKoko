Community Pulse

Local CSV reporting support for Community QA review

Community Pulse is a local CSV-based reporting support prototype that turns fictional or manually prepared feedback into QA-aware, human-reviewed reports and External QA handoff context. It preserves exact quotes, keeps evidence traceable, and makes safe workflow boundaries visible.

Project README Full report

What It Models

High-engagement feedback, organized into reviewable QA context

Local feedback records

Manually prepared CSV rows model fictional accounts, posts, topics, sentiment labels, and exact feedback notes.

Structured review

The CLI produces Markdown reports with sentiment counts, local feedback inputs, topic splits, exact quotes, and human follow-up notes.

External QA handoff

A compact sample export shows how community signals can become QA-ready context without Jira integration or live platform access.

Traceable Evidence Handling

Exact quotes and source alignment stay reviewable

  • Representative quotes are copied exactly from the CSV `text` field.
  • The External QA handoff sample is tested against the high-engagement CSV.
  • Local input, affected area, and sentiment are checked for alignment with the same CSV row.
  • Missing context remains a human review responsibility before routing to QA, design, production, community, or External QA partners.

Safe Workflow Boundaries

Local reporting support, not live platform automation

  • No live ingestion, scraping, monitoring, browser automation, or platform collection.
  • No private APIs, proprietary systems, Jira integration, or live community platform connections.
  • No automated moderation, automated player decisions, generated screenshots, generated evidence, or generated art.
  • No LLM calls, embeddings, OCR, or hidden external processing.

Portfolio Value

Why this belongs in a QA portfolio

Community Pulse shows practical QA Lead and Community QA judgment: traceability, triage thinking, quote preservation, evidence handling, human review, External QA handoff discipline, and cross-functional communication. It is intentionally scoped as a local demo so the recruiter-facing evidence stays clear and safe.
