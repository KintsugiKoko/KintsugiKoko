Three.js / WebGL · Playable Browser Prototype

WARDRAGONS: The Ashen Frontier

Build a foothold, equip for the fight, and defend it. WARDRAGONS combines first-person combat with a persistent equipment collection, faction allies, outpost capture, and construction. The single-player prototype runs directly in the browser with keyboard/mouse and touch controls.

Play WARDRAGONS Project Overview

Combat And Handling

Sword contact windows, bow draw and release, projectile cover collision, and equipment-specific recovery connect animation to gameplay rules.

Economy And Persistence

Shop purchases, owned equipment, loadout slots, loot, and outpost state connect short-term choices to a locally saved expedition.

World And Input Systems

Raised terrain, traversal, allied units, fortifications, and touch input create connected collision, targeting, and state-management challenges.

Built with JavaScript, HTML/CSS, Three.js/WebGL, Web Audio, and browser-local saves. Game development uses agent-assisted implementation and human review. Prototype scope: single-player play, not multiplayer.

Design Process

From player goal to reviewable iteration

  • State the player-facing goal and the behavior that should communicate success.
  • Map system ownership so one feature does not silently become responsible for every reward, UI, save, and presentation rule.
  • Build or document the smallest version that can answer a design question.
  • Use PIE checks, playtests, and scenario notes to separate observed behavior from assumptions.
  • Revise the design, implementation boundary, feedback, or documentation based on evidence.
