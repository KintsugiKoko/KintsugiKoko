About

A portfolio with the learning left visible

This site is the front page for my learning portfolio. I am using GitHub to document what I practice, what I build, what confuses me, and what I want to understand next.

It is a working portfolio, not a finished showcase. The goal is to show real progress with clear notes, honest project status, and beginner-friendly explanations.

Why Games

The interest that keeps me curious

Games combine systems, stories, feedback, creativity, teamwork, and problem solving. That mix is part of why learning software development feels personal instead of abstract. I am starting with the foundations first so future game-inspired projects can have clearer structure, better documentation, and more confidence.

Goals

What I am building toward next

My next steps are intentionally practical. I want each project to build a skill I can explain, test, document, and connect back to game development or QA work.

  • Improve the QA Bug Report Tool with clearer triage summaries, better examples, and more test coverage.
  • Keep documenting Nyx as a real Unreal learning project without pretending the prototype is finished.
  • Practice GitHub issue, branch, PR, review, and release-note habits in small repeatable loops.
  • Build more beginner-friendly Python utilities for QA, logs, notes, and documentation workflows.
  • Create a small game-inspired web interaction when the HTML, CSS, and JavaScript foundations are ready.
