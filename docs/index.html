About

Senior QA judgment across systems, data, and live-service delivery

I have worked across MMO systems, live-service data, backend and API validation, tools, shops and MTX, build pipelines, exploratory testing, regression coverage, and release-readiness reporting.

How I Work

Coverage, evidence, and clear release risk

  • Translate feature goals and system behavior into risk-based test plans, executable suites, and acceptance criteria.
  • Manage external QA tasking and execution with clear scope, setup, evidence standards, intake review, and follow-through.
  • Plan and execute PTR sessions with players, gather test data, and turn observed behavior into actionable risk reporting.
  • Parse Grafana telemetry to investigate defects, identify recurring or exploit-related trends, and isolate component weaknesses.
  • Connect backend data, API behavior, tools, configuration, and player-facing outcomes during investigation.
  • Give developers concise repro steps, logs, telemetry, build context, severity, and residual-risk notes.
  • Use agent assistance for scoped implementation and evidence gathering while keeping human approval and release decisions explicit.
