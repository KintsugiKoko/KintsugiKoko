Nyx Test Planner

A browser-based planning board for turning Nyx gameplay ideas into clear QA scenarios, risk notes, and exportable Markdown test plans.

This is a portfolio-safe planning prototype. It does not connect to Unreal, private tools, Jira, studio data, or automated test runners. Keith still reviews the plan and owns the testing decisions.

Purpose Show test-planning judgment before implementation gets messy. Risk, scope, status, expected results, and follow-up notes stay visible.
