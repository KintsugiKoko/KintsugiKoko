# Week 01 - Starting the Rebuild

## Why I'm Starting

This is the beginning of my public learning journey after Intrepid closed. That change forced me to pause and think seriously about what I want to build next.

Games are still a big part of what motivates me. I love how games combine creativity, systems, problem solving, and community. I want to understand more about how software, tools, workflows, and interactive experiences are made, so I am starting with the basics and documenting the process honestly.

## What I Learned This Week

- I learned that a GitHub repository can be more than a place to store files. It can also be a record of learning, reflection, and progress.
- I learned the basic structure of a portfolio repository, including a main `README.md`, project notes, learning logs, and a simple GitHub Pages folder.
- I learned that Markdown is useful for writing clear notes and organizing documentation.
- I started to understand how small files can work together to explain a larger learning story.

## What Still Feels Confusing

- Git and GitHub still feel new, especially the difference between local files, commits, branches, and what shows up online.
- I am still learning how to know when something is "done enough" to save, commit, or share.
- HTML and CSS make sense at a high level, but I still need more practice understanding how page structure and styling work together.
- I want to get more comfortable reading file paths, links, and repository structure without feeling lost.

## What I Practiced

- Setting up a simple repository structure.
- Organizing folders for learning logs, project notes, and a GitHub Pages site.
- Reading and editing Markdown files.
- Thinking about how to describe my learning without exaggerating my experience.
- Using AI assistance to draft, revise, and organize beginner-friendly documentation.

## How GitHub Fits Into the Journey

GitHub gives this rebuild a visible place to grow. Instead of only learning privately, I can keep track of what I try, what I understand, and what I still need to revisit.

Right now, GitHub feels like both a tool and a habit. The tool part is learning repositories, commits, files, and links. The habit part is showing up consistently, writing things down, and letting progress be visible even when it is still early.

## How AI Helped Me Learn

AI helped me turn scattered thoughts into a clearer structure. It helped draft the first version of the portfolio, suggest sections, explain what different files are for, and keep the tone honest.

I do not want AI to replace understanding. I want to use it as support while I learn how the pieces fit together. This week, it helped me get started instead of staring at a blank page.

## Connection to Games

Games are the reason this path feels connected to something personal. I am interested in how games are built, how systems are designed, and how tools help teams create complex experiences.

This week was not about building a game yet. It was about setting up the foundation so future game-inspired projects have a place to live, a way to be documented, and a clear path for improvement.

## Next Steps

- Keep practicing Git and GitHub basics.
- Fill in more learning logs as I study and build.
- Review the GitHub Pages homepage and make sure it represents the learning journey clearly.
- Start a small beginner project and document it with the project template.
- Continue connecting technical practice back to games, tools, and rebuilding after a hard reset.
