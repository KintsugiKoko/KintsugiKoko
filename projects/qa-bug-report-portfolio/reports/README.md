# Bug Report Archive

This folder will hold practice bug reports for the QA Bug Report Portfolio project.

Reports should be based on real observations from small websites, tools, personal practice projects, or game-inspired web experiments. They should not invent issues or exaggerate impact.

## Naming Format

Use a simple numbered format:

- `001-short-description.md`
- `002-short-description.md`
- `003-short-description.md`

## Reminder

The goal is to practice clear documentation:

- What happened?
- What did I expect?
- Can someone else reproduce it?
- What did I learn by writing it down?
