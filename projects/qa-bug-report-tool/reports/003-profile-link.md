# Project card opens the wrong QA report

| Field | Details |
| --- | --- |
| Severity | Low |
| Priority | Medium |
| Environment | Windows 11, Edge, portfolio homepage |
| Repro Rate | 1/1 |

## Steps to Reproduce

1. Open the portfolio homepage.
2. Find the QA Bug Report Portfolio card.
3. Click the report link.

## Expected Result

Link opens the QA bug report portfolio README.

## Actual Result

Link opens the project template instead.

## Notes

The page still works, but the link sends visitors to the wrong learning artifact.
