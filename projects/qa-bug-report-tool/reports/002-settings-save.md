# Save button stays disabled after changing volume

| Field | Details |
| --- | --- |
| Severity | Medium |
| Priority | High |
| Environment | Windows 11, Firefox, settings prototype |
| Repro Rate | 2/2 |

## Steps to Reproduce

1. Open Settings.
2. Move the volume slider from 50 to 70.
3. Check the Save button.

## Expected Result

Save button becomes enabled after a setting changes.

## Actual Result

Save button stays disabled, so the new value cannot be saved.

## Notes

This blocks a basic settings flow in the practice page.
