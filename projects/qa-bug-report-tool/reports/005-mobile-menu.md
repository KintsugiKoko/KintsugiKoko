# Mobile menu overlaps the page title

| Field | Details |
| --- | --- |
| Severity | Low |
| Priority | Medium |
| Environment | iPhone size viewport, Chrome DevTools, portfolio homepage |
| Repro Rate | 2/2 |

## Steps to Reproduce

1. Open the homepage at 390px width.
2. Tap the menu button.
3. Look at the page title area.

## Expected Result

Menu opens below the header without covering the title.

## Actual Result

Menu covers part of the page title.

## Notes

This kind of issue matters because visitors may browse the portfolio from a phone.
